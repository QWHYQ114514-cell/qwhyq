## 要解决什么

需要一个地方记录做过的事，同时以后能直接当作品集用。不想用现成博客模板，一是学不到东西，二是不够像自己。

## 怎么做

- Astro 做静态生成，页面基本没有 JS，只有滚动揭示那二十来行。
- 内容用 Markdown + 类型校验：字段写错或漏写，构建直接失败。
- 视觉上定了一套 token——六种中性色、一个粉色、三条缓动曲线，全站只从这里取值，避免颜色慢慢变脏。
- 部署在 Vercel，推到 GitHub 自动构建。

## 结果

首屏不需要等 JS，页面就是 HTML + CSS。手机 4G 下 1 秒内能读。

## 复盘

一开始打算用 React 写，动手之后发现整站没有一个需要客户端状态的地方——框架在这里只是负担。另外粉色最难的部分不是选色，是**控制用量**：定了一份白名单，只允许它出现在七个位置，新增一处必须先删一处。
