## 赛题

面向大一新生的程序设计赛，往年是 8 道题、3 小时，C/C++ 或 Python 都可以。

## 准备

- 每周做 3 道基础题，重点是把输入输出和边界情况写对——这类比赛丢分大多不是算法不会，是细节没处理好。
- 补一下 C++ 的 STL 容器。Python 写得熟，但有些题的时间限制对 Python 不友好。
- 把过去三年的题按知识点分类，先从数组和字符串开始。

## 复盘

比赛还没开始。等打完回来把这节补上：不管结果如何，都要写清楚哪道题卡住了、卡在什么地方、下次怎么避免。
